# 评测维度

评测不是为了给项目打分好玩，而是帮读者判断：这个 Skill 值不值得花时间安装、阅读或改造。

## 信息完整度

- 来源链接是否稳定。
- 作者和维护者是否清楚。
- 许可证是否明确。
- README 是否能让人知道怎么开始。
- 示例是否足够具体。

## 可用性

- 安装步骤是否清楚。
- 依赖是否仍然可用。
- 示例是否能复现。
- 输出是否符合项目描述。
- 普通用户是否能直接用，还是需要开发经验。

## 复用价值

- 是否解决具体任务。
- 是否能适配不同输入。
- 是否有清楚的输入和输出。
- 是否容易改成自己的版本。
- 是否能和常见 Agent 或工具配合。

## 维护状态

- 最近更新时间。
- issue 和 PR 是否有回应。
- 是否有版本发布。
- 是否有用户反馈。
- 是否存在明显废弃信号。

## 风险

- 是否要求上传敏感数据。
- 是否依赖不明服务。
- 是否存在版权或许可证问题。
- 是否可能诱导用户生成不可靠结论。
- 是否有安全、合规或伦理风险。

## 建议结论

最后用一句话给结论：

- 推荐收录。
- 可以作为参考。
- 暂时观察。
- 不建议收录。

结论后面要给理由，不要只写态度。
