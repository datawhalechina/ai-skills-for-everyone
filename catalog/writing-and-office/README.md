- [Weekly Status](weekly-status.md)：本项目维护的轻量周报 Skill，搭配 starter 给普通用户使用。
- [Lark CLI Agent Skills](lark-cli.md)：飞书 / Lark 官方命令行和 Agent Skills，适合站会汇总、文档和任务工作流。
- [MLE-Agent](mle-agent.md)：从 GitHub 或本地 Git 仓库生成技术周报，可参考。
