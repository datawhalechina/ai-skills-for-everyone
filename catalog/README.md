# Skill 目录

这里放单个 Skill 的中文收录卡片。

[Skill Hub 总表](INDEX.md) 会按大类、小类和推荐位整理所有已收录条目。读者想快速找东西，先看总表；想看某个项目细节，再进单个卡片。

`catalog/` 按大场景分文件夹，尽量和 `collections/` 保持同一套分类。这样读者从场景合集点进来时，不会在一个大目录里翻文件。

当前分类：

- [写作与办公](writing-and-office/README.md)
- 学习与研究：待有条目后创建。
- 内容创作：待有条目后创建。
- [开发与调试](coding-and-devtools/README.md)
- 自动化流程：待有条目后创建。

每个卡片都应该说明：

- 来源链接。
- 作者或组织。
- 许可证。
- star 数和核查日期。
- 适合场景。
- 使用方式。
- 优点、限制和风险。
- 是否推荐收录。

新增条目前，请先复制 `templates/skill-card-template.md`。

文件建议放在对应分类里，例如：

```text
catalog/writing-and-office/ppt-master.md
catalog/learning-and-research/example-skill.md
catalog/coding-and-devtools/example-skill.md
```
