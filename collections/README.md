# 场景合集

这里按任务场景整理 Skill。读者应该先来这里，而不是先翻 catalog。

合集不是链接列表，而是精选入口。每个大类会继续拆成小类，每个小类尽量只保留 2 到 3 个推荐位：

| 推荐位 | 适合谁 | 选择标准 |
| --- | --- | --- |
| 最省心 | 完全普通用户 | 最容易跑起来，最好有教程、starter 或清楚的中文上手路线。 |
| 进阶 | 已经会用 Agent 的用户 | 能力更完整，但可能需要安装依赖、读文档或处理配置。 |
| 可改造 | 开发者或轻技术用户 | 适合二次开发、接入工作流，或者作为自己 Skill 的底座。 |

“最省心”推荐位可以是一个独立 Skill，也可以是我们给某个复杂 Skill 做好的 starter 路线。

如果一个小类暂时找不到靠谱项目，就先留空。宁可少，也不硬凑。

## 场景合集

- [写作与办公](writing-and-office.md)：周报、邮件、会议纪要、长文档摘要、PPT、表格、SOP、项目计划、文档润色。
- [学习与研究](learning-and-research.md)：资料整理、论文阅读、知识卡片、复习计划。
- [内容创作](content-creation.md)：选题、文章、图片提示词、短视频脚本。
- [开发与调试](coding-and-devtools.md)：前端、后端、测试、部署、日志分析。
- [自动化流程](automation-workflows.md)：重复任务、文件处理、数据同步。

## 每个合集怎么写

每个合集都要回答：

- 这个场景下用户常见任务是什么。
- 值得优先看的 Skill 有哪些。
- 每个小类的最省心、进阶、可改造位置分别是谁。
- 每个 Skill 的差异是什么。
- 有哪些明显风险或限制。
