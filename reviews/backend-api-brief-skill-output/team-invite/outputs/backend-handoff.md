# 后端开发交接：邀请成员加入团队

## 需求摘要

为团队协作工具新增“邀请成员加入团队”能力。团队管理员可通过邮箱创建邀请，选择目标角色并发送邀请邮件。被邀请人点击链接后接受邀请，系统将其加入团队。管理员需要能查看待接受邀请、重新发送邀请、撤销邀请。

建议假设：邀请有效期默认 7 天；邀请状态包含 `pending`、`accepted`、`revoked`、`expired`；接受邀请时要求登录用户邮箱与邀请邮箱一致。

## 建议接口

| 方法 | 路径 | 用途 | 权限 | 备注 |
| --- | --- | --- | --- | --- |
| `POST` | `/teams/{team_id}/invitations` | 创建邀请并触发邮件发送 | 团队管理员 | 校验邮箱、角色、重复邀请 |
| `GET` | `/teams/{team_id}/invitations?status=pending` | 查看团队邀请列表 | 团队管理员 | 需要分页和状态筛选 |
| `POST` | `/teams/{team_id}/invitations/{invitation_id}/resend` | 重新发送邀请 | 团队管理员 | 建议刷新 `expires_at`，待确认 |
| `POST` | `/teams/{team_id}/invitations/{invitation_id}/revoke` | 撤销邀请 | 团队管理员 | 仅允许撤销 `pending` 邀请 |
| `GET` | `/invitations/{token}` | 查看邀请摘要 | 已登录或匿名，待确认 | 不返回敏感信息 |
| `POST` | `/invitations/{token}/accept` | 接受邀请并加入团队 | 被邀请用户 | 需校验 token、邮箱、状态、有效期 |

## 权限规则

- 创建、重发、撤销、查看邀请列表必须在后端校验团队管理员权限。
- 接受邀请时必须校验邀请 token 有效、未过期、未撤销、未接受。
- 建议强制登录用户邮箱与邀请邮箱一致，否则可能出现邀请被转发后越权加入团队。
- 目标角色必须受白名单限制，不能让请求体提交任意角色名。
- 如果目标邮箱已是团队成员，创建邀请应返回冲突错误，不应重复创建。

## 数据变更提醒

建议新增 `team_invitations` 表或等价集合：

| 字段 | 说明 |
| --- | --- |
| `id` | 邀请 ID |
| `team_id` | 所属团队 |
| `email_normalized` | 规范化后的邮箱，小写去空格 |
| `role` | 接受后授予的团队角色 |
| `status` | `pending` / `accepted` / `revoked` / `expired` |
| `token_hash` | 邀请 token 的 hash，不建议存明文 |
| `expires_at` | 过期时间 |
| `invited_by` | 邀请人 |
| `accepted_by` / `accepted_at` | 接受人和接受时间 |
| `revoked_by` / `revoked_at` | 撤销人和撤销时间 |
| `created_at` / `updated_at` | 审计时间 |

建议增加唯一性约束：同一 `team_id + email_normalized` 只能有一条有效 `pending` 邀请。接受邀请和创建成员关系最好放在同一个事务里，避免“邀请已接受但成员没创建”的半成功状态。

## 错误码与状态码

- `201 Created`：邀请创建成功。
- `200 OK`：重发、撤销、接受成功。
- `400 Bad Request` / `422 Unprocessable Entity`：邮箱格式、角色、请求体不合法。
- `401 Unauthorized`：未登录。
- `403 Forbidden`：不是团队管理员，或接受邀请的账号邮箱不匹配。
- `404 Not Found`：团队或邀请不存在。
- `409 Conflict`：邮箱已是团队成员，或已有待接受邀请。
- `410 Gone`：邀请已过期、已撤销或已接受。
- `429 Too Many Requests`：邀请或重发频率过高。
- `502 Bad Gateway` / `503 Service Unavailable`：邮件服务不可用，是否保留邀请记录待确认。

## 测试建议

- 团队管理员可以成功创建邀请，普通成员不能创建邀请。
- 已是团队成员的邮箱不能再次邀请。
- 已有 `pending` 邀请时，创建接口返回 `409` 或提示使用重发接口。
- 过期、撤销、已接受邀请不能再次接受。
- 接受邀请后创建团队成员，并把邀请状态改为 `accepted`。
- 接受邀请时登录用户邮箱不匹配应返回 `403`。
- 重发邀请应校验权限、频率限制和过期时间刷新规则。
- 邮件服务失败时覆盖返回值、重试策略和记录状态。
