# 小白原始需求：邀请成员加入团队

我有一个团队协作工具，里面有团队、项目和成员。

现在我想加一个“邀请成员加入团队”的功能。管理员可以输入对方邮箱，给他发邀请。被邀请的人点链接以后，可以加入团队。

我现在能想到的是：

- 只有团队管理员可以邀请新成员。
- 邀请时可以选择角色，比如普通成员、项目管理员。
- 邀请链接最好有有效期，比如 7 天。
- 如果这个邮箱已经在团队里，就不要重复邀请。
- 如果之前邀请过但还没接受，可以重新发送邀请。
- 被邀请的人接受以后，应该自动成为团队成员。
- 管理员最好能看到哪些邀请还没接受，也能撤销邀请。

我不知道这里后端要怎么设计接口，也不知道邀请状态、权限、邮件发送、过期链接这些应该怎么处理。
