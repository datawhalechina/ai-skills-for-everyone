# 论文阅读 Skill 评测用例

这份记录用来测试“读一篇论文并总结”这类 Skill 的真实表现。

先用同一组 case 跑下面三个候选：

| Skill / 项目 | 定位 | 重点观察 |
| --- | --- | --- |
| `huggingface-papers` | 最省心，给论文链接让 Agent 读 | 能不能快速抓住主线，是否保留来源 |
| `paper-qa` | 进阶，适合多篇论文问答和引用 | 回答是否有引用，能不能处理多文档对比 |
| `ChatPaper` | 中文高星工具，适合论文总结和翻译 | 中文总结是否顺，配置和运行是否小白友好 |

## 评测时统一看什么

- 是否能顺利读取论文，少折腾环境。
- 摘要是否真的来自论文，而不是泛泛而谈。
- 是否区分“论文原文结论”和“模型自己的判断”。
- 是否能讲清楚方法、实验、贡献和局限。
- 中文表达是否适合普通学习者。
- 对长论文、多篇论文时是否会丢重点。

## Case 1：入门，读懂一篇经典论文

任务目标：测试 Skill 能不能把一篇经典论文讲清楚。

论文：

- Attention Is All You Need
- arXiv: https://arxiv.org/abs/1706.03762

测试提示词：

```text
请阅读这篇论文，并用中文帮我总结。

论文链接：https://arxiv.org/abs/1706.03762

请按下面结构输出：
1. 一句话说明这篇论文解决了什么问题。
2. 它提出的核心方法是什么。
3. Transformer 和之前 RNN / CNN 方法相比，关键区别在哪里。
4. 论文里最重要的实验结论是什么。
5. 这篇论文为什么后来影响这么大。
6. 如果我是初学者，读这篇论文前需要先知道哪些概念。
7. 用不超过 200 字写一个适合放进学习笔记的总结。

要求：
- 不要堆术语。
- 不确定的地方请标出来。
- 尽量保留论文里的关键来源信息。
```

理想输出应该做到：

- 能讲明白 self-attention 和 Transformer 的基本意义。
- 不只是说“提出了 Transformer”，还要说明它为什么替代循环结构。
- 对初学者友好，不把摘要写成一堆英文术语。

## Case 2：进阶，读一篇方法型论文

任务目标：测试 Skill 能不能读懂“方法 + 实验 + 适用场景”。

论文：

- Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks
- arXiv: https://arxiv.org/abs/2005.11401

测试提示词：

```text
请阅读这篇论文，并用中文帮我做一份技术阅读笔记。

论文链接：https://arxiv.org/abs/2005.11401

请重点回答：
1. RAG 想解决什么问题。
2. 它把检索器和生成器怎么接在一起。
3. RAG-Sequence 和 RAG-Token 的区别是什么。
4. 论文做了哪些任务或数据集上的实验。
5. 它相比只靠参数记忆的模型有什么优势。
6. 它有哪些局限，哪些地方今天看可能已经过时。
7. 如果我要把它用在企业知识库问答里，哪些结论可以借鉴，哪些不能直接照搬。

最后请给出：
- 3 条核心 takeaway
- 3 个我应该继续追问的问题

要求：
- 只基于论文内容总结，延伸判断要单独标为“我的理解”。
- 如果能给出处或章节线索，请尽量给。
```

理想输出应该做到：

- 能解释清楚 RAG 的两段式思路。
- 不把 RAG 简化成“先搜索再回答”这么粗。
- 能从论文实验过渡到真实工程使用，但不乱吹。

## Case 3：高级，多篇论文对比

任务目标：测试 Skill 能不能处理多篇论文，并做有来源的横向比较。

论文：

- Attention Is All You Need：https://arxiv.org/abs/1706.03762
- GPT-4 Technical Report：https://arxiv.org/abs/2303.08774
- Llama 2: Open Foundation and Fine-Tuned Chat Models：https://arxiv.org/abs/2307.09288

测试提示词：

```text
请阅读下面三篇论文，并做一份中文对比报告：

1. Attention Is All You Need
https://arxiv.org/abs/1706.03762

2. GPT-4 Technical Report
https://arxiv.org/abs/2303.08774

3. Llama 2: Open Foundation and Fine-Tuned Chat Models
https://arxiv.org/abs/2307.09288

请输出：
1. 三篇论文各自的核心问题和核心贡献。
2. 它们分别代表了大模型发展的哪一个阶段。
3. 从模型结构、训练方式、评测方式、安全对齐、开放程度这几个维度做一个表格对比。
4. 哪些内容是论文明确写出来的，哪些是你根据背景做的推断。
5. 如果我是普通学习者，推荐按什么顺序读，为什么。
6. 用 500 字以内写一段“大模型从 Transformer 到 GPT-4 / Llama 2 的发展脉络”。

要求：
- 每个关键判断尽量标明来自哪篇论文。
- 不要把没有公开的训练细节当成确定事实。
- 对 GPT-4 Technical Report 这类披露不完整的论文，要明确说明信息边界。
```

理想输出应该做到：

- 能处理三篇论文，不只分别摘要。
- 能指出 GPT-4 论文披露有限，不编造训练细节。
- 能把 Transformer、闭源能力报告、开源权重模型之间的差异讲清楚。
- `paper-qa` 这类工具如果能给出引用，会在这个 case 里明显占优。

## 初步预期

- `huggingface-papers` 可能最适合 Case 1：链接给进去，快速出中文总结。
- `paper-qa` 可能最适合 Case 3：多篇论文对比、带引用问答。
- `ChatPaper` 如果中文输出和 PDF 处理顺，适合做中文用户的可改造路线。
