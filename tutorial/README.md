# 教程目录

这不是项目文档目录，是给普通人跟着做的教程。

第一次来，先看第 0 课。它会帮你判断：你是完全小白、用过 Agent 但没用过 Skill、已经用过 Skill，还是已经会搓 Skill。

## 第 0 课

[先选你的路线](00-getting-started.md)

你会知道自己该从哪一课开始，不用硬着头皮从头读到尾。

## 第 1 课

[用开源 PPT Skill 生成可编辑 PPT](01-use-ppt-skill.md)

你会跟着做出一个 `.pptx` 文件。  
这节课会讲 Trae 怎么装、工作区怎么打开、材料放哪里、提示词复制哪段、生成结果去哪找。

## 第 2 课

[用 Trae 安装已知 Skill，再按需求找到新 Skill](02-find-and-install-skills.md)

你会学会两件事：已经有地址时，怎么让 Trae 先判断、再安装、再测试；只有需求时，怎么拆关键词、找候选、做筛选。

## 第 3 课

[使用我们维护的 Skill 库](03-use-skill-library.md)

你会学会读这个仓库自己的 Skill 库：先从场景合集找，再看 Skill 卡片，最后进 starter 工作区。

## 第 4 课

[把自己的重复工作搓成 Skill](04-make-your-own-skill.md)

你会做一个最小版 Skill 工作区。  
它不一定需要代码，先把一个重复任务整理成固定流程：输入、步骤、输出、样例、提示词。这里会用周报 Skill 说明：好的输出不只是分栏整理，还要帮助读者判断当前状态、风险和下一步动作。

## 第 5 课

[Agent 使用进阶](05-agent-advanced.md)

你会了解不同 Agent 的适合场景，以及在 Trae 里接入自定义 API 时要注意什么。

## 第 6 课

[用 Skills Manager 管理多个 Skill](06-manage-many-skills.md)

你会用一个假的测试 Skill，试跑 Skills Manager 的导入、preset 和同步流程。
这节课是可选进阶内容，适合已经装过多个 Skill 的人。

## 不同读者怎么走

- 完全小白：第 0 课 → 第 1 课。
- 用过 Agent，没用过 Skill：第 0 课 → 第 2 课。
- 已经用过 Skill：第 0 课 → 第 3 课。
- 已经会搓 Skill：第 0 课 → 第 3 课 → 第 4 课。
- 想了解 Agent 进阶用法：第 0 课 → 第 5 课。
- 已经有很多 Skill，想统一管理：第 0 课 → 第 6 课。
