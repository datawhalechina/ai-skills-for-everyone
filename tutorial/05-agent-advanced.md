# 第 5 课：Agent 使用进阶

前面几课默认你用 Trae 跑流程。这样对普通人最友好：能打开文件夹，能看到文件，能在执行命令前点确认，也能比较自然地让 Agent 解释每一步。

但用 Skill 用久了，你会遇到两个新问题：

- 我是不是只能用 Trae？
- 我能不能接自己的模型 API？

这一课不教复杂开发，只讲普通人和轻技术用户最容易用到的进阶选择。

## 先分清三类 Agent

### 1. 图形界面 Agent

代表就是 Trae 这类桌面工具。

适合：

- 普通用户。
- 第一次接触 Skill 的人。
- 想看见文件、目录和命令确认的人。
- 想把材料放进文件夹，再让 Agent 帮忙处理的人。

优点是直观。缺点是有些复杂自动化不一定方便，具体能力也会随版本变化。

### 2. 编辑器型 Agent

这类 Agent 通常在代码编辑器里工作。它能读写项目文件，也能运行命令。

适合：

- 已经习惯用编辑器的人。
- 想改 starter、改脚本、改提示词的人。
- 需要同时看多个文件的人。

如果你只是想生成 PPT，不一定需要它。  
如果你想维护一个 Skill 工作区，它会更顺手。

### 3. 命令行型 Agent

这类 Agent 主要在终端里工作，更适合懂一点技术的人。

适合：

- 已经熟悉命令行的人。
- 想批量处理文件的人。
- 想把 Skill 接进脚本或自动化流程的人。
- 想更清楚地控制工作目录、依赖和日志的人。

普通用户不用一上来走这条路。它很强，但也更容易让人迷路。先用 Trae 跑通一遍，再考虑升级。

## Trae 里可以接自己的 API 吗

有些版本的 Agent 工具支持自定义模型或 API Key。  
如果你的 Trae 版本也支持，可以在设置里找类似“模型”“API”“自定义模型服务”的位置。

这件事的意义是：你不一定只能用工具默认提供的模型。你可以接入自己已有的模型服务，费用、速度和可用性可能更适合你。

但这里有几个原则：

- API Key 只填在工具设置里，不要直接发到聊天框。
- 不要把 API Key 写进 `README.md`、提示词、截图或公开仓库。
- 如果项目里需要 `.env` 文件，确认 `.env` 已经被 `.gitignore` 忽略。
- 不知道 Key 有没有泄露时，直接去服务商后台重置。
- 不确定费用时，先跑小样，不要一上来生成几十页、图片、旁白和视频。

如果你不懂 API Key，也没关系。第 1 课不要求你必须配置它。

## 什么时候继续用 Trae

满足这些情况，就继续用 Trae：

- 你只是想使用 Skill，不想维护工具链。
- 你需要看见文件夹和输出文件。
- 你希望每条命令执行前都有确认。
- 你主要处理 PPT、周报、纪要、摘要、表格报告这类办公任务。

一句话：能用 Trae 稳定跑通，就别急着换。

## 什么时候考虑命令行型 Agent

遇到这些情况，再考虑命令行型 Agent：

- 你已经能看懂基本命令。
- 你要批量处理很多文件。
- 你想把某个 Skill 做成固定脚本。
- 你要维护多个 starter 工作区。
- 你需要更细地控制依赖、日志、版本和输出路径。

它适合“我想把流程做得更自动”的人，不适合“我第一次想试试”的人。

## 命令确认要养成习惯

不管用哪种 Agent，都不要盲点确认。

让 Agent 执行命令前，先让它用中文回答：

```text
请先解释这条命令：
1. 它要做什么？
2. 会不会联网？
3. 会读写哪些文件夹？
4. 会不会安装依赖？
5. 有没有删除、覆盖、上传文件的风险？
6. 如果我不执行，有没有替代方案？
```

如果解释里出现这些动作，要格外小心：

- 删除文件。
- 覆盖整个目录。
- 上传材料。
- 修改系统环境变量。
- 安装来源不明的软件。
- 要求你粘贴 API Key、账号密码或验证码。

看不懂就停下来。停一下比修一堆烂摊子轻松多了。

## 建议的升级顺序

不用一口气把所有工具都学完。

更稳的顺序是：

1. 先用 Trae 跑通第 1 课。
2. 学会让 Trae 解释命令。
3. 学会在 Trae 里打开不同 starter。
4. 如果你的版本支持，再尝试配置自己的 API。
5. 等你开始维护多个工作区，再考虑编辑器型或命令行型 Agent。

工具越强，越需要边界。对普通人来说，最重要的不是“用最强 Agent”，而是能稳定、安全、低成本地把自己的任务做完。

## 本课练习

选一个你已经跑通过的 starter，做三件事：

1. 让 Trae 用中文解释一次环境检查命令。
2. 找到 Trae 的模型或 API 设置入口，但不要乱填 Key。
3. 写下你现在适合哪种 Agent：图形界面、编辑器型，还是命令行型。

如果你现在的答案是“继续用 Trae”，这完全没问题。能稳定完成任务，就是好选择。
